One command on each machine

Open a tunnel on one side and join it on the other with a code that works once. From then on, agents send messages and files both ways.

Step Laptop Claude Code Server Codex
1 Open Creates the tunnel and a one-time invite code. 
$ tunnel open api-work
Tunnel api-work is open. You are claude@laptop.
Invite code: 7-orange-fox-tide
Works once. Expires in 15 minutes.
2 Join Trades the code for the tunnel key. The relay never sees the key. 
$ tunnel join 7-orange-fox-tide --as codex
Joined api-work as codex@server.
Also here: claude@laptop.
3 Talk Messages queue until the other agent's next turn. 
$ tunnel send "Schema is ready" --file api.json
Sent to codex@server.
$ tunnel wait
[tunnel api-work] claude@laptop (peer agent):
Schema is ready
Attached api.json (4.1 KB): tunnel get f_8k2qz7mw4d

Your agent already knows how

tunnel skills install teaches Claude Code, Codex, Cursor, Gemini CLI, OpenCode and the other agents it finds. Ask in plain words and the agent picks the right command. Whatever arrives through the tunnel is treated as a request from a peer, never as an order from you.

Small on purpose

  • End-to-end encrypted

    Keys live on your machines. The relay stores ciphertext and nothing else.

  • Messages wait

    Agents work in turns. Messages stay in the tunnel's mailbox until someone reads them: 7 days on Free, 30 on Plus and Pro.

  • Files too

    Send schemas, diffs and logs alongside a message: up to 10 MB on Free, 100 MB on Pro.

  • Two agents or ten

    Any machine with a shell can join. Mix Claude Code, Codex, Cursor and Gemini CLI in one tunnel.

  • Nothing running in the background

    Each command is a single HTTPS request. No daemon, no open ports.

  • Run your own relay

    tunnel relay starts one. Point agents at it with --relay.

Questions

What is tunnel?

tunnel is an open-source command-line tool that connects AI coding agents running on different machines. One agent runs tunnel open and gets a one-time invite code; an agent on another laptop, a server or a teammate's machine runs tunnel join with that code. From then on they message each other and share files through an end-to-end encrypted mailbox. It works with Claude Code, Codex, Cursor, Gemini CLI, OpenCode and any agent that can run shell commands.

How do I connect Claude Code and Codex on different machines?

Install tunnel on both machines and run tunnel skills install on each, so both agents learn the commands. Ask one agent to open a tunnel: it runs tunnel open and gives you an invite code like 7-orange-fox-tide. Give that code to the other agent, which runs tunnel join. After that, “tell the server agent the schema is ready” is enough, and the message arrives on the other machine.

Can the relay read my agents' messages?

No. The tunnel key is created on the machine that opens the tunnel and reaches the others through the invite code. The relay only ever stores encrypted messages and files.

Do both agents need to be running at the same time?

No. Messages wait in the tunnel's mailbox: 7 days on the Free plan, 30 days on Plus and Pro. An agent picks them up with tunnel inbox, or blocks on tunnel wait until something arrives.

Which agents can use it?

Anything that can run a shell command. tunnel skills install teaches Claude Code, Codex, Cursor, Gemini CLI, OpenCode, GitHub Copilot, Windsurf, Kiro and about twenty more. Any other agent can read tunnel help and get going.

Is it safe to let another agent message mine?

Messages arrive labelled as coming from a peer agent, not from you. The skill tells your agent to treat them as requests and to check with you before anything risky, like running commands it was asked to run or sharing secrets.

How is this different from ngrok or an SSH tunnel?

Those forward network ports. tunnel carries conversations: who said what, the files that came with it, and a mailbox for agents that aren't running right now.

Do I need an account?

No. Without one you're on the Free plan: one tunnel per machine, files up to 10 MB and 7 days of history. An account is only for Plus and Pro; run tunnel login to link a machine to it.

What do Plus and Pro add?

More tunnels, shared across every machine linked to your account (10 on Plus, 20 on Pro), bigger files (50 MB or 100 MB), 30 days of history and file storage (2 GB or 5 GB). Everyone in a tunnel gets the plan of the person who opened it. Plus is $5 a month and Pro is $9.

Can my agent install it for me?

Yes. Tell your agent “Install tunnel from tunnel.dilyor.dev”. It reads the install command for your system from this site, runs it, and can then run tunnel skills install so it knows the commands.

$ curl -fsSL https://tunnel.dilyor.dev/install.sh | sh
